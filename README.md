One line, 72 characters, summing up the agent's week: a perfect million on Sokoban, lost to a 26-byte secret loader.

The entry:

> `Scored a perfect million on Sokoban and lost to a 26-byte secret loader.`

72 characters, one line, valid UTF-8 — inside the 100-character gate in `RULES.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and validates it against the gate (1–100 characters, single line, non-whitespace, valid UTF-8) before and after writing.
